# 北航雨课堂自动续播（Edge 扩展）

这个浏览器扩展适用于 `https://buaa.yuketang.cn/ai-workspace/lms-graph/` 下的课程视频页面。开启后，它会在当前视频自然播放结束时打开目录中的下一段视频，并将播放速度设为 2 倍。切换到其他标签页或切回时，如果页面暂停了正在播放的视频，扩展会尝试恢复。

当前版本：**1.2.6**。

## 安装与更新

1. 下载本项目的源代码 ZIP，并解压到本地文件夹。该文件夹中应直接包含 `manifest.json`。
2. 在 Edge 地址栏打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择该文件夹。
3. 如果已经加载了同一文件夹，在扩展管理页点击“重新加载”。然后刷新雨课堂课程页面，让新脚本生效。
4. 打开课程视频页，确认右下角面板显示 **v1.2.6**，点击“开始自动续播”。

## 使用方式

- 当前视频已暂停时，可点击面板中的“继续播放当前视频”。
- 播放过程中切换标签页，扩展会处理后台暂停，以及切回页面后的短暂延迟暂停。
- 切回后，用户在页面内点击或按键会结束这次自动恢复，以便手动控制播放。正常的手动暂停会被保留。
- 点击“停止自动续播”会取消待执行的下一节切换，不会暂停当前视频。
- 扩展开关按标签页保存；关闭标签页或重启浏览器后默认关闭。

浏览器禁止自动播放、标签页被节能模式冻结、电脑休眠、课程站点结构变化等情况仍可能使播放中断。此时请回到视频页，按面板提示继续。扩展不会修改课程完成度或向站点写入观看记录。

## 范围与权限

扩展仅在上述北航雨课堂课程路径运行。唯一申请的扩展权限是 `storage`，用于保存本地标签页状态。代码没有遥测、外部依赖、额外网络请求或远程执行脚本。

## 开发

使用 Node.js 运行 `node --test tests/extension.test.cjs`。测试覆盖课程识别、目录续播、倍速、标签页切换恢复、手动暂停、自动播放被阻止以及错误处理。
